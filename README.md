# Confluence — Pi Multi-Agent Workspace

本地运行、MIT 开源的多智能体协作 Web 工作区。基于 **@earendil-works/pi-coding-agent 1.4.0** 的真实 AgentSession，非多模型轮流聊天。各成员独立推理、主动定向提问、委派、领取共享任务、交付文本成果。实际测试记录见 [VERIFICATION.md](VERIFICATION.md)。

## 启动

需要 Node.js 22.13+（本机验证版本 24.22.1）。

1. 打开项目文件夹，双击 `start.cmd`。脚本会等待本地服务就绪，然后自动用默认浏览器打开工作区。重复双击时会直接打开已经运行的网页，不会启动第二个服务。
2. 首次启动如果还没有依赖，脚本会自动执行 `npm ci`。看到浏览器打开 `http://127.0.0.1:4317` 即表示启动成功。
3. 需要停止后台服务时，双击同一文件夹中的 `stop.cmd`。

也可以在终端手动启动：

1. 在项目文件夹空白处右键，点击“在终端中打开”。或在 PowerShell 输入：
   ```powershell
   cd "C:\Users\heyon\Desktop\AI Agent\CodexLab\pi-workspace"
   ```
2. 首次安装或复制到另一台机器后，输入 `npm ci`，等待安装结束。本机已安装依赖，可跳过。
3. 输入 `npm start`。看到 `Pi Workspace: http://127.0.0.1:4317` 表示服务已启动。
4. 在浏览器地址栏输入 `http://127.0.0.1:4317`。保持终端开启；关闭时在终端按 Ctrl+C。不要同时启动两个使用同一数据目录的服务。

## 配置与使用

> 从旧版升级时，历史工作区、Agent 和模型会自动迁移。旧版从未将 API Key 写入磁盘，因此升级后需要在“配置中心”为每个接入重新输入一次密钥。之后密钥会加密保存，无需每次重填。

1. 点击左下角“配置中心”，按页面顺序先添加“接入配置”。填写名称、API 基础地址、协议和认证方式。Agnes 的基础地址为 `https://api.agnes-ai.cn/v1`，协议为 `openai-completions`。
2. 在接入配置中填写 API Key 并保存。密钥由 Windows DPAPI 按当前用户加密，保存在 `data/credentials.enc`，不会进入 SQLite、浏览器状态、源码或日志；关闭并重新启动后可继续使用。也可以只填写环境变量名。修改 API 地址、协议或认证方式时，需要重新输入密钥，防止旧密钥被发往新地址。
3. 在“接入配置”的已保存项右侧点击“模型目录”，可从供应商读取模型；也可在下方“模型”区域点击“添加模型”手动填写。分别设置显示名称、模型 ID、上下文长度和输出上限。接入凭据可供同一服务下的多个模型复用。
4. 在“Agent 身份”区域设置名称、职责、默认模型和成果权限。身份、接入和模型互相独立；多个 Agent 可以使用同一模型，同一 Agent 也能在工作区中切换模型。
5. 点击“新建工作区”，填写名称、勾选至少两个成员，点击“创建工作区”。每个工作区为每位成员新建独立 Pi Session。
6. 在底部输入任务，选择“@ 全体成员”或指定成员，点击“发送”。可要求设计师主动向评审员请求检查。带“定向交接”的消息来自真实 `send_message` 工具调用。
7. 右侧查看成员状态、任务板和成果。点击成果可阅读全文，再点击“下载文本”保存。聊天中的文本以纯文本呈现，代码块与 Markdown 原文可直接复制。
8. “暂停”中止当前请求并保留等待队列；暂停期间仍可发送修正意见，然后点击“继续”。“终止”中止请求并清空队列。已执行的工具和已产生的成果不会撤销。达到预算后，点击右侧“调整”增加预算，再点击“继续”。
9. 在右侧成员卡片的下拉菜单中选择其他模型，即可在同一个对话中切换。切换会写入一条系统记录；该成员的 Pi Session 文件、上下文水位、任务和历史均保持不变。成员正在生成时需先点击“暂停”。
10. 左侧点击历史工作区即可恢复查看。数据保存在 `data/`；重启后不会自动恢复执行，以免意外再次调用模型。点击“继续”显式恢复。

## 架构

```text
浏览器（原生 ES modules / CSS）
  ├─ POST：消息、运行控制、配置、预算
  └─ SSE：流式文本、共享消息、状态、重连快照
       │
Node.js HTTP 服务（仅 127.0.0.1）
       │
事件驱动调度器 ── SQLite WAL：共享记录 / 队列 / 任务 / 成果 / 工具幂等结果
  ├─ Agent A → 独立 Pi AgentSession → 模型服务 A
  ├─ Agent B → 独立 Pi AgentSession → 模型服务 B
  └─ Agent N → 独立 Pi AgentSession → 模型服务 N
       └─ 各自 Pi JSONL：私有上下文、压缩摘要、工具结果、同步水位
```

- `src/engine.mjs`：定向投递、去重、单 Agent 串行、工作区并发、全局并发、运行边界与工具。
- `src/pi-session.mjs`：原生 Pi SessionManager 恢复、SettingsManager 自动压缩/有限重试、显式资源加载器、当前所选模型和请求节流。
- `src/secrets.mjs`：使用 Windows 当前用户 DPAPI 加密整个凭据仓库，串行原子写入 `credentials.enc`；明文只在服务进程内存和发往所选 API 的请求中存在。
- `src/store.mjs`：Node 原生 SQLite，WAL + FULL 同步；共享会话与 Pi 上下文分开保存。
- `server.mjs`：HTTP / SSE、输入校验、同源与 Host 检查、CSRF token、静态资源与 API。
- `public/`：无需构建、无 CDN 的响应式 Web 客户端。

用户消息唤醒指定成员或全体。Agent 的 `send_message` 唤醒其选择的目标，调度器不决定讨论顺序，也不自动轮询模型。普通最终回复仅显示而不广播唤醒，避免每一句话引发所有成员回复。无待办事件时自然静止，不进行后台自我思考。

共享消息具有单调序号。每次激活只读取该 Agent 水位后的消息，剔除自身已在 Pi 中出现的消息，按大小分批提交。同步标记写入 Pi 用户消息，恢复时从原生日志重建水位。压缩由 Pi 原生负责，出现模型错误或压缩失败时暂停，并保留原始历史，不清空上下文、不无限重试。每次激活重新建立 SDK 包装，但打开同一个持久 Pi Session，并非创建空白上下文。

工具：

| 工具 | 行为 |
|---|---|
| `send_message` | 主动提问、委派、反馈，目标可为单个队友或 all |
| `task_board` | 创建、原子领取、完成、列出任务；只有负责人能完成 |
| `save_artifact` | 可选权限，创建不可覆盖文本成果，保存在 SQLite |
| `read_artifact` | 查看同一工作区成果列表或正文 |

工具以 Agent ID + Pi toolCallId 去重。所有工具变更在单线程同步段执行，领取冲突不会双重成功。成果名称不作为服务器文件路径，`../` 不会导致目录越界。未开放 Pi 原生 Shell/读写工具，也不加载用户目录中的扩展、技能或 AGENTS 文件。

## 运行限制

- 工作区 2–8 名成员，最多 30 个接入、100 个模型、30 个 Agent 身份和 100 个工作区；每个工作区最多 100 个任务和 100 个成果。
- 全局最多 4 个激活，每个工作区 1–4 个，同一个 Agent Session 不并发执行。
- 默认 24 次激活 / 60000 tokens；每次激活最多 8 次模型请求、16 次工具调用。
- 激活时限为 120 秒加 8 个配置的请求间隔。等待节流时可取消。
- Token 是服务商上报的会话用量；正在运行的并发请求、自动压缩和服务商统计差异可能产生超额。这不是精确账单硬限额。
- 保存的 API Key 只能由保存它的 Windows 用户账户解密。删除 `data/credentials.enc` 会清除全部已保存密钥，不影响聊天和模型配置。

## 验证命令

```powershell
npm test
# 先在终端自行设置 AGNES_API_KEY；不在命令中输出密钥。
$env:LIVE_GAP_MS = '65000'
npm run test:live
# 恢复最近一次真实测试的持久会话：
node scripts/resume-live.mjs
```

`test:live` 必须有真实密钥，缺失时失败退出，不回退到模拟响应。它通过真实 HTTP API 创建两位 Agent、发任务、等待模型工具调用，核对双向交接、任务完成、成果保存和独立 Session。报告保存在忽略提交的 `artifacts/live-report.json`，不包含凭据。免费服务限流时可能需要较长等待和显式恢复。

本机 UI 验证使用 `scripts/browser-qa.mjs`，复用工作区相邻的 `chrome-cdp` 项目；它不是发布包的运行依赖。该脚本会在独立测试数据目录中创建一个无密钥接入、两个模型和两个 Agent 身份，验证房间内模型切换、刷新后恢复和响应式布局，并保留 Chrome 窗口。

## 已知局限

这是本地单用户版本，没有团队登录、远程部署、文件执行沙箱、网络搜索、Shell、MCP 管理或多人权限。适用于讨论、方案审查和文本交付，不能宣称已经执行外部代码或修改用户文件。若要添加执行能力，应在独立隔离进程中实现权限、审批和资源限制。

Pi 日志和 SQLite 不共享同一个事务。正常停止、恢复及工具幂等有覆盖，但系统在两次持久化之间断电时，不保证跨存储严格 exactly-once；尤其最终文本可能已经进入 Pi 而尚未进入共享聊天。不会自动重放不确定的外部副作用。数据库目前存整个工作区快照，长期大量会话应迁移至按消息分表与分页。

SSE 断线重连恢复已提交消息，断线期间尚未提交的文本片段不回放。没有富 Markdown 渲染、图片输入和附件上传。模型是否遵循协作与停止指令取决于模型能力，但调度和工具资源上限由宿主强制执行。

自动压缩通过 SDK 配置启用；真实溢出压缩、压缩失败后的所有恢复分支、非 OpenAI 兼容协议尚未全部进行真实模型验证。配置中的模型 ID 代表服务商接口标识，不证明其背后模型供应商或架构。
